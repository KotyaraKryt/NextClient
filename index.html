Современный клиент CS 1.6 A modern CS 1.6 client

Модификация Counter-Strike 1.6 с новыми возможностями для игроков и для разработчиков серверных модов на AMX Mod X. Работает поверх оригинальной игры из Steam. A Counter-Strike 1.6 modification with new features for players and for AMX Mod X server developers. It runs on top of the original game from Steam.

ВозможностиFeatures

Всё, чего не хватало в 1.6, без замены самой игры. Everything 1.6 was missing, without replacing the game itself.

На базе Steam-версииBuilt on the Steam version

Работает с движком 8684 из Steam и дорабатывает его на лету, не подменяя оригинальные файлы. Works with the 8684 engine from Steam and extends it at run time, without replacing the original files.

ЗащитаProtection

Протектор не даёт серверу выполнить на клиенте вредоносные команды и испортить конфиг. The protector stops servers from running malicious commands on the client and breaking its config.

Новый интерфейсNew interface

Переработанное меню и темы оформления, аватарки игроков из Steam, цветной чат в консоли. A redesigned menu and themes, Steam avatars of the players, colored chat in the console.

Быстрые загрузкиFast downloads

При входе на сервер видно, сколько файлов осталось, их размер и скорость. Мастер-сервер можно сменить. On connect you see how many files are left, their size and the speed. The master server can be changed.

Тонкие настройкиFine-tuning

FOV для 16:9 и отдельно для модели оружия, новые прицелы, расширенная лента убийств, покачивание оружия из csldr. FOV for 16:9 and for the weapon model separately, new crosshairs, an extended killfeed, viewmodel sway from csldr.

Для разработчиковFor developers

API для AMX Mod X: песочница кваров, спрайты на экране, настройка килфида, проверка клиента и HWID, здоровье больше 255. An AMX Mod X API: a cvar sandbox, on-screen sprites, killfeed customization, client verification and HWID, health above 255.

УстановкаInstallation

Четыре шага, и можно играть. Four steps and you're in.

  1. В Steam переключите CS 1.6 на бету steam_legacy — Pre-25th Anniversary Build: NextClient работает только с движком 8684. In Steam, switch CS 1.6 to the steam_legacy — Pre-25th Anniversary Build beta: NextClient only works with engine 8684.
  2. Скопируйте всю папку Half-Life куда-нибудь вне папки Steam. Copy the whole Half-Life folder somewhere outside the Steam folder.
  3. Распакуйте в эту копию все файлы NextClient. Unpack all the NextClient files into that copy.
  4. Запустите игру через cstrike.exe. Start the game with cstrike.exe.

Никогда не кладите файлы NextClient в папку игры внутри Steam: это приведёт к VAC-бану. Пиратские сборки не поддерживаются. Never put the NextClient files into the game folder inside Steam: it leads to a VAC ban. Pirated copies are not supported.
