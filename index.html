Ставится в копию Steam-версии игры на Windows и Linux. Добавляет радар с картой уровня, защиту от вредных команд сервера, статус в Discord, быстрые загрузки и настройку модели оружия, а движок остаётся оригинальным.It goes into a copy of the Steam version of the game, on Windows and Linux, and adds a radar with the level map, protection from harmful server commands, a Discord status, fast downloads and weapon model tuning, while the engine stays the original.

01

Браузер серверовServer browser

Флаги стран, режимы игры и фильтры, которые сразу показывают, сколько серверов останется. Избранное и история под рукой, мастер-сервер можно сменить.Country flags, game modes and filters that show at once how many servers will be left. Favorites and history at hand, and the master server can be changed.

02

РадарRadar

Карта уровня строится сама, плоская или с текстурами, а слой выбирается по высоте, на которой вы стоите. Ники, здоровье союзников (если его передаёт сервер), следы движения и цели, а при открытой таблице счёта видна вся карта.The level map builds itself, flat or textured, and the layer follows the height you stand at. Names, teammates' health (when the server sends it), movement trails and objectives, and the whole map while the scoreboard is open.

03

Discord

В статусе Discord видно, на каком сервере вы играете и сколько там игроков, а ещё когда вы подключаетесь или смотрите демо. Друзья заходят к вам через Discord, даже если игра у них ещё не запущена. Статус, имя сервера и вход к вам выключаются кварами cl_discordrpc, cl_discordrpc_server и cl_discordrpc_join.Your Discord status shows the server you play on and how many are there, and when you're connecting or watching a demo. Friends join you through Discord, even when their game isn't running yet. The status, the server's name and joining you turn off with cl_discordrpc, cl_discordrpc_server and cl_discordrpc_join.

04

Расширенный килфидExtended killfeed

Видно, как именно убили: через стену, через дым, без прицела, в прыжке, вслепую, с помощью напарника. Работает на серверах с ReGameDLL 5.26 и новее, если там не выключен mp_deathmsg_flags.See how exactly a kill happened: through a wall, through smoke, without scoping, in the air, while blinded, with a teammate's assist. Works on servers with ReGameDLL 5.26 or later, unless they turn mp_deathmsg_flags off.

05

Тонкая настройкаFine tuning

Модель оружия, боббинг, инерция и камера настраиваются по отдельности: смещение и FOV модели, стиль покачивания с живым превью, пресеты от классики до CS:GO для быстрого старта, а своими настройками можно поделиться одним кодом. Многое здесь взято из csldr.The weapon model, bobbing, inertia and camera are tuned separately: model offset and FOV, a bob style with a live preview, presets from classic to CS:GO for a quick start, and a single code to share your settings. Much of it comes from csldr.

Не будет ли VAC-бана?Will I get a VAC ban?

Играйте из копии игры вне папки Steam, как в разделе Установка. Класть файлы NextClient в папку игры внутри Steam нельзя: именно это приводит к VAC-бану.Play from a copy of the game outside the Steam folder, as in Installation. Работает ли на пиратской версии?Does it work with a pirated copy?

Нет. Нужна купленная CS 1.6 в Steam на бете steam_legacy и запущенный Steam. Эмулятора Steam в NextClient нет.No. You need a purchased CS 1.6 on Steam on the steam_legacy beta, with Steam running. NextClient has no Steam emulator.

Почему антивирус ругается?Why does my antivirus complain?

NextClient перехватывает функции движка прямо в памяти, и некоторые антивирусы по эвристике принимают это за вредоносное поведение. С версии 2.5.1 официальные сборки собирает GitHub Actions из исходников этого репозитория и подписывает их происхождение. Проверить архив можно командой gh attestation verify NextClient-<версия>.zip -R CS-NextClient/NextClient или сверив его SHA-256 со страницей релиза. Как сообщить о ложном срабатывании, описано здесь.NextClient detours engine functions in memory, and some antivirus engines take that for malicious behavior by heuristics. Since 2.5.1, official builds are made by GitHub Actions from the source code of this repository and carry a signed provenance attestation. You can check an archive with gh attestation verify NextClient-<version>.zip -R CS-NextClient/NextClient or by comparing its SHA-256 with the release page. How to report a false positive is described here.

Есть ли версия для Linux?Is there a Linux version?

Да, начиная с 2.6.0. Это родная сборка, она запускается через Steam Runtime скриптом nextclient.sh и работает с обычной и Snap-версией Steam. Нужны 32-битные glibc 2.43 или новее, библиотеки C++ и SDL2, а для расширенного радара — OpenGL 2.1 с поддержкой FBO. Кнопка «Скачать» сама предложит её, если вы зашли с Linux. HTML-интерфейс на CEF пока есть только на Windows.Yes, since 2.6.0. It's a native build that runs through the Steam Runtime with the nextclient.sh script and works with the regular and the Snap Steam. It needs 32-bit glibc 2.43 or later, the C++ libraries and SDL2, and OpenGL 2.1 with framebuffer objects for the advanced radar. The Download button offers it by itself when you visit from Linux. The CEF-based HTML interface is Windows only for now.

Как вернуться к обычной CS?How do I go back to the regular CS?

NextClient живёт в отдельной копии игры, а версия в Steam остаётся нетронутой: просто запустите игру из Steam. Чтобы удалить NextClient, удалите папку с копией.NextClient lives in a separate copy of the game and the Steam one stays untouched: just start the game from Steam. To remove NextClient, delete the folder with the copy.

Нужно ли что-то ставить на сервер?Does the server need anything?

Нет, NextClient играет на любых серверах. Модуль NextClientServerApi нужен, только если сервер хочет пользоваться возможностями NextClient: песочницей кваров, спрайтами, килфидом и остальным.No, NextClient plays on any server. The NextClientServerApi module is only for servers that want NextClient's features: the cvar sandbox, sprites, the killfeed and the rest.

Как сменить мастер-сервер?How do I change the master server?

В файле platform/config/MasterServer.vdf: Selected — номер сервера из списка Servers, считая с нуля. По умолчанию это tsarvar.com.In platform/config/MasterServer.vdf: Selected is the number of a server from the Servers list, counting from zero. The default is tsarvar.com.
