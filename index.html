РадарRadar

Карта уровня строится сама, слой выбирается по высоте, на которой вы стоите. Ники, здоровье союзников (если его передаёт сервер), следы движения и цели, а при открытой таблице счёта видна вся карта.The level map builds itself, and the layer follows the height you stand at. Names, teammates' health (when the server sends it), movement trails and objectives, and the whole map while the scoreboard is open.

Расширенный килфидExtended killfeed

Установка за пару минутSet up in a couple of minutes

Четыре шага, и можно играть.Four steps and you're in.

  1. В Steam переключите CS 1.6 на бету steam_legacy: NextClient работает с движком 8684.In Steam, switch CS 1.6 to the steam_legacy beta: NextClient works with engine 8684.
  2. Скопируйте папку Half-Life куда-нибудь вне папки Steam.Copy the Half-Life folder somewhere outside the Steam folder.
  3. Распакуйте в эту копию архив NextClient.Unpack the NextClient archive into that copy.
  4. Запустите Steam, затем cstrike.exe из копии.Start Steam, then cstrike.exe from the copy.
  1. В Steam переключите CS 1.6 на бету steam_legacy и установите Linux-версию игры.In Steam, switch CS 1.6 to the steam_legacy beta and install the Linux version of the game.
  2. Нужны 32-битный glibc 2.43 или новее и 32-битные библиотеки C++, на Ubuntu так:You need 32-bit glibc 2.43 or later and the 32-bit C++ libraries, on Ubuntu like this: sudo dpkg --add-architecture i386 && sudo apt update && sudo apt install libstdc++6:i386 libgcc-s1:i386
  3. Скопируйте папку Half-Life вне папки Steam и распакуйте в копию архив NextClient с заменой файлов.Copy the Half-Life folder outside the Steam folder and unpack the NextClient archive into the copy, replacing files.
  4. Запустите Steam, затем в папке копии:Start Steam, then in the copy's folder: chmod +x nextclient.sh cstrike.exe && ./nextclient.sh

Никогда не кладите файлы NextClient в папку игры внутри Steam: это приведёт к VAC-бану. Пиратские сборки не поддерживаются.Never put the NextClient files into the game folder inside Steam: it leads to a VAC ban. Pirated copies are not supported.

Вопросы и ответыFAQ

Коротко о том, что спрашивают чаще всего.Short answers to what people ask most.

Не будет ли VAC-бана?Will I get a VAC ban?

Играйте из копии игры вне папки Steam, как в разделе Установка. Класть файлы NextClient в папку игры внутри Steam нельзя: именно это приводит к VAC-бану.Play from a copy of the game outside the Steam folder, as in Installation. Never put the NextClient files into the game folder inside Steam: that is what leads to a VAC ban.

Работает ли на пиратской версии?Does it work with a pirated copy?

Нет. Нужна купленная CS 1.6 в Steam на бете steam_legacy и запущенный Steam. Эмулятора Steam в NextClient нет.No. You need a purchased CS 1.6 on Steam on the steam_legacy beta, with Steam running. NextClient has no Steam emulator.

Почему антивирус ругается?Why does my antivirus complain?

NextClient перехватывает функции движка прямо в памяти, и некоторые антивирусы по эвристике принимают это за вредоносное поведение. С версии 2.5.1 официальные сборки собирает GitHub Actions из исходников этого репозитория и подписывает их происхождение. Проверить архив можно командой gh attestation verify NextClient-<версия>.zip -R CS-NextClient/NextClient или сверив SHA-256 под кнопкой «Скачать». Как сообщить о ложном срабатывании, описано здесь.NextClient detours engine functions in memory, and some antivirus engines take that for malicious behavior by heuristics. Since 2.5.1, official builds are made by GitHub Actions from the source code of this repository and carry a signed provenance attestation. You can check an archive with gh attestation verify NextClient-<version>.zip -R CS-NextClient/NextClient or by comparing its SHA-256 with the one under the Download button. How to report a false positive is described here.

Есть ли версия для Linux?Is there a Linux version?

Да, начиная с 2.6.0. Это родная сборка, она запускается через Steam Runtime скриптом nextclient.sh и работает с обычной и Snap-версией Steam. Нужны 32-битные glibc 2.43 или новее, библиотеки C++ и SDL2, а для расширенного радара — OpenGL 2.1 с поддержкой FBO. Кнопка «Скачать» сама предложит её, если вы зашли с Linux. HTML-интерфейс на CEF пока есть только на Windows.Yes, since 2.6.0. It's a native build that runs through the Steam Runtime with the nextclient.sh script and works with the regular and the Snap Steam. It needs 32-bit glibc 2.43 or later, the C++ libraries and SDL2, and OpenGL 2.1 with framebuffer objects for the advanced radar. The Download button offers it by itself when you visit from Linux. The CEF-based HTML interface is Windows only for now.

Как вернуться к обычной CS?How do I go back to the regular CS?

NextClient живёт в отдельной копии игры, а версия в Steam остаётся нетронутой: просто запустите игру из Steam. Чтобы удалить NextClient, удалите папку с копией.NextClient lives in a separate copy of the game and the Steam one stays untouched: just start the game from Steam. To remove NextClient, delete the folder with the copy.

Нужно ли что-то ставить на сервер?Does the server need anything?

Нет, NextClient играет на любых серверах. Модуль NextClientServerApi нужен, только если сервер хочет пользоваться возможностями NextClient: песочницей кваров, спрайтами, килфидом и остальным.No, NextClient plays on any server. The NextClientServerApi module is only for servers that want NextClient's features: the cvar sandbox, sprites, the killfeed and the rest.

Как сменить мастер-сервер?How do I change the master server?

В файле platform/config/MasterServer.vdf: Selected — номер сервера из списка Servers, считая с нуля. По умолчанию это tsarvar.com.In platform/config/MasterServer.vdf: Selected is the number of a server from the Servers list, counting from zero. The default is tsarvar.com.
